    Set up one-tap alarms

    iPhone and iPad only let apps create alarms through the Shortcuts app. Build this one-step shortcut once and every alarm button here works with a single tap.

    1. Open Shortcuts and tap + to start a new shortcut.
    2. Search for Create Alarm (from the Clock app) and tap it.
    3. In that action, tap the time and choose Shortcut Input.
    4. Tap the name at the top, choose Rename, call it Sleep Alarm, then tap Done.

    The first time it runs, iOS asks to let the shortcut create alarms. Tap Allow. With iCloud on for Shortcuts, it syncs to your iPad too.
